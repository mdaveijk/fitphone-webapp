# fitphone-webapp
A mobile-first web application for Fitphone, a research initiative promoting healthy and conscious smartphone use.

The standalone [Check screenshot recognition prototype](prototype/README.md) uses React, TypeScript, Vite and browser-only Tesseract.js OCR.

```sh
cd prototype
npm ci
npm run dev
```

See the prototype README for tests, temporary localStorage persistence, supported parsing patterns and the real-device testing limitations.
